# Decisions

Status: Accepted

Architecture decision records (ADRs) are the highest authority in the [documentation](../README.md). Each ADR records one decision area: its context, the decision, the alternatives considered and the consequences.

## Rules

- **ADRs are never edited after acceptance**, except for typos and links. To change a decision, write a new ADR that supersedes the old one, and set the old one's status to `Superseded by ADR-NNNN`.
- New ADRs use the [template](adr-template.md) and the next free number.
- An ADR is accepted when it is merged following the [workflow](../process/workflow.md).
